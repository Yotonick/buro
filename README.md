# Бюро Невозможного Ремонта

Кооперативная 3D физ-комедия для 2–4 друзей. Godot 4.7, GDScript, Windows PC.
Неуклюжие ремонтники чинят невозможное с помощью изоленты и какой-то матери.

## Документация
- [PROJECT_STATUS.md](PROJECT_STATUS.md) — где мы сейчас и что дальше (читать первым)
- [GAME_DESIGN_DOCUMENT.md](GAME_DESIGN_DOCUMENT.md) — дизайн игры
- [TECHNICAL_ARCHITECTURE.md](TECHNICAL_ARCHITECTURE.md) — архитектура
- [ASSET_CATALOG.md](ASSET_CATALOG.md) — ассеты, источники, лицензии

## Как играть с друзьями (план)
Radmin VPN → один нажимает «Создать игру», остальные «Подключиться по IP» и вводят Radmin-IP хоста.
