### Среда разработки
- Облачная Linux-машина: 2 ядра, 7 ГБ ОЗУ. Рабочая папка не переживает чат.
- Доступно: git-чтение публичных репозиториев GitHub, apt, pip, npm. Недоступно: релизы GitHub, godotengine.org, kenney.nl.
- **Как получить Godot в новом чате (1 минута вместо часа сборки):**
  `git fetch --depth 1 origin toolchain:refs/remotes/origin/toolchain && git show origin/toolchain:godot-4.7.2-linux-editor.xz | xz -d > /tmp/godot && chmod +x /tmp/godot`
- Если пересобирать: `tools/build_godot.sh` (~45 мин; прерванная сборка scons начинается заново — запускать и дожидаться в одном ходе).
- Скриншоты: `xvfb-run -a -s "-screen 0 1280x720x24" godot --path game --rendering-driver opengl3 --write-movie /tmp/shot/f.png --fixed-fps 5 --quit-after 6` (нужен apt-пакет xvfb).
- Быстрый запуск для тестов: `godot --path game -- --host --name=X` / `-- --join=IP --name=Y` (+ `--port`, `--report-after`, `--quit-after`).

### Режим работы (с 2026-11-10): ПК владельца
- Папка на ПК: `D:\CLAUDE\buro` — это и есть клон репозитория; рядом лежит `Godot_v4.7.2-stable_win64.exe` (в git не попадает).
- **У Claude нет командной строки на ПК** — только чтение/запись файлов в этой папке. Поэтому: код пишется и проверяется в облаке (Linux-Godot из ветки `toolchain`), пушится в `main`, а владелец запускает двойным кликом:
  - `setup.bat` — один раз: скачивает проект в папку, проверяет Git и Godot;
  - `play.bat` — подтягивает свежую версию (`git pull`) и запускает игру;
  - `editor.bat` — открывает редактор Godot;
  - `build_exe.bat` — качает шаблоны экспорта (один раз, ~1 ГБ) и собирает `build\buro.exe`.
- Журналы скриптов и игры пишутся в `logs\` на ПК (в git не попадают) — Claude читает их оттуда.
- С ПК ничего не пушится; файлы проекта на ПК руками не правим, чтобы `git pull` не спотыкался.

- `setup.bat` и `play.bat` проверены на ПК владельца; `build_exe.bat` — ещё нет (в облаке проверено только, что пресет читается и путь к шаблонам совпадает).
- Vulkan в облаке недоступен, поэтому кадры снимаются только через OpenGL (нужны apt-пакеты `xvfb libgl1-mesa-dri`).
