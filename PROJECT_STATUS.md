### Сделано и проверено (2026-11-10)
- **Godot 4.7.2 собран из исходников** под Linux, запускается. Сжатый бинарник лежит в ветке `toolchain` (см. ниже) — пересобирать не нужно.
- **Каркас проекта** в `game/`: настройки, сетевая сессия за интерфейсом транспорта (ENet), главное меню «Создать игру / Подключиться по IP», лобби со списком бригады и подсказкой Radmin-IP.
- **Автотест сети** `game/tests/net_test.sh` — PASS: хост + 3 клиента на одной машине видят одинаковый состав; одинаковые имена разводятся («Вася», «Вася 2»); 5-й игрок получает отказ «мест нет»; клиенты замечают закрытие хоста; занятый порт и мёртвый адрес дают понятные сообщения.
- Меню отрисовано в облаке через виртуальный экран (xvfb + программный OpenGL) — кириллица отображается.
- Ассеты получены: 6 архивов в `assets_inbox/` (см. ASSET_CATALOG.md). Не хватает Kenney Impact Sounds.

### Решения владельца
- Персонаж: **«Комбез»** с рисованным 2D-лицом, без симуляции ткани, с петлёй на спине для переноски.

- Ассеты выбирает студия, владелец кладёт zip в `assets_inbox/`.

### Среда разработки
- Облачная Linux-машина: 2 ядра, 7 ГБ ОЗУ. Рабочая папка не переживает чат.
- Доступно: git-чтение публичных репозиториев GitHub, apt, pip, npm. Недоступно: релизы GitHub, godotengine.org, kenney.nl.
- **Как получить Godot в новом чате (1 минута вместо часа сборки):**
  `git fetch --depth 1 origin toolchain:refs/remotes/origin/toolchain && git show origin/toolchain:godot-4.7.2-linux-editor.xz | xz -d > /tmp/godot && chmod +x /tmp/godot`
- Если пересобирать: `tools/build_godot.sh` (~45 мин; прерванная сборка scons начинается заново — запускать и дожидаться в одном ходе).
- Скриншоты: `xvfb-run -a -s "-screen 0 1280x720x24" godot --path game --rendering-driver opengl3 --write-movie /tmp/shot/f.png --fixed-fps 5 --quit-after 6` (нужен apt-пакет xvfb).
- Быстрый запуск для тестов: `godot --path game -- --host --name=X` / `-- --join=IP --name=Y` (+ `--port`, `--report-after`, `--quit-after`).
